# 正则匹配



正则适合处理结构相对稳定的文本。先确定目标：是查找片段、校验整个字符串，还是提取字段？在 Python 中，可分别用 `search()`、`fullmatch()` 和捕获分组。

## 基本使用规则

### 普通字符

```
abc
```



### 特殊字符

```
. 匹配任意单个字符
* 匹配前一个字符0次或者多次
+ 匹配前一个字符1次或多次
```



## 案例库



### 匹配某一行含有某个字符串的行

```
.*字符串.*

.*flag.*

```



### 匹配同时含有多个字符串的行

```
^(?=.*data)(?=.*information).*$


```



### 匹配某字符串开头

```
^start.*
```



### 匹配以某字符串结尾

```
.*end$
```



### 匹配含有数字的行

```
.*[\d].*
```



### 匹配字母

```
.*[a-z].*
```



### 匹配倒数第五个字符为a的行

```
^.*a.{4}$
```



### 匹配换行符

```
\n
```



### 匹配所有大写字母

```
[A-Z]
```

## 用几条样例验证规则

假设课程编号由两个 ASCII 大写字母、一个连字符和四位数字组成，使用 `fullmatch` 避免把带前缀或后缀的值误判为合法。

```python
import re

code = re.compile(r"[A-Z]{2}-[0-9]{4}")
assert code.fullmatch("CS-0206")
assert not code.fullmatch("课程 CS-0206")
assert not code.fullmatch("CS-２０２６")

log = re.compile(r"\[(?P<level>[^\]]+)\]\s+(?P<message>.+)")
assert log.fullmatch("[INFO] cache rebuilt").groupdict() == {
    "level": "INFO",
    "message": "cache rebuilt",
}
```

每条规则配一组正常值、边界值和反例。要把用户输入当作普通文本查找，可以先用 `re.escape()` 转义；输入已经是 JSON、HTML 或 CSV 时，优先用相应解析器。

参考：[Python re 标准库文档](https://docs.python.org/3/library/re.html)。
